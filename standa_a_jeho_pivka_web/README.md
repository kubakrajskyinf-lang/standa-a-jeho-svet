# Standa a jeho pivka – webová verze

Tato verze je upravená pro hraní přímo v internetovém prohlížeči.

## Lokálně
Otevři `index.html` v prohlížeči.

## Online
Celou složku můžeš nahrát na službu pro statické weby (např. GitHub Pages nebo Netlify).
Není potřeba Python ani Pygame.

Poznámka: původní Pygame zvuky nejsou součástí nahraného souboru, takže webová verze používá jednoduché syntetické zvuky. Highscore se ukládá do localStorage prohlížeče.
